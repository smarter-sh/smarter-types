Changelog
=========

Releases are made by `semantic-release <https://semantic-release.gitbook.io/>`__
from the project's conventional commit messages, which also write
``CHANGELOG.md``. Each release's notes are on its
`GitHub release page <https://github.com/smarter-sh/smarter-types/releases>`__.

Versions follow `semantic versioning <https://semver.org/>`__:

- a **patch** release (0.1.1) fixes bugs,
- a **minor** release (0.2.0) adds something, such as a new SAM kind or cli
  command, and keeps working code working,
- a **major** release (1.0.0) can break code, e.g. by removing or renaming a
  member, or changing a value that manifests or stored journal entries hold.
