Installation
============

Requirements
------------

- Python 3.10 or newer

Its only dependency is `inflection <https://pypi.org/project/inflection/>`__,
which pluralizes a kind's name.

Install the package
-------------------

Install it from PyPI:

.. code-block:: console

    $ pip install smarter-types

You rarely need to install it yourself. The Smarter platform and the Smarter
Python SDK (``pip install smarter-api``) both depend on it, and re-export its
classes from their own modules: see :doc:`guide/why`.

Next: :doc:`quickstart`.
